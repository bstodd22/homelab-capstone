# Homelab Capstone — Hybrid Security Monitoring Lab

An ongoing cybersecurity home lab focused on infrastructure deployment,
network segmentation, and centralized log collection across on-premises
and cloud environments.

## Completed Work

### On-Premises Infrastructure
- Built a Proxmox environment with Windows Server and Linux virtual machines.
- Configured network segmentation using VLANs and pfSense firewall rules.

### Wazuh
- Deployed and configured Wazuh for centralized log collection.
- Configured Windows Server and Linux virtual machines to forward logs to Wazuh.

### Azure and Microsoft Sentinel
- Extended the on-premises environment to Azure through Azure Arc.
- Configured Windows endpoints to send Windows Security Events to Microsoft Sentinel.
- Integrated Microsoft Sentinel with the Microsoft Defender portal.

## Skills Demonstrated
- Virtual infrastructure deployment with Proxmox
- Network segmentation using VLANs and pfSense
- Windows and Linux log forwarding
- Wazuh deployment and configuration
- Hybrid cloud integration with Azure Arc
- Microsoft Sentinel security-event collection
- Sentinel integration with the Microsoft Defender portal

## Current Scope

Completed work focuses on deploying infrastructure and configuring log
collection. Attack simulations, KQL analysis, security investigations,
custom detection rules, alert tuning, and incident response exercises
have not yet been performed.

Integration with the Microsoft Defender portal does not represent
Defender for Endpoint deployment or Defender XDR investigation experience.
